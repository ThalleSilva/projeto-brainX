# Projeto BrainX

## Sobre o Projeto

O **BrainX** é uma plataforma desenvolvida com foco em organização, estudo e gerenciamento inteligente de informações, utilizando tecnologias modernas para entregar uma experiência eficiente e intuitiva.

O projeto é dividido em:

* **Backend**: API responsável pelas regras de negócio e gerenciamento de dados.
* **Frontend**: Interface responsável pela experiência do usuário.

---

## Tecnologias Utilizadas

### Backend

* .NET
* ASP.NET Core
* Entity Framework

### Frontend

* React
* TypeScript
* Tailwind CSS

---

## Estrutura do Projeto

```bash
projeto-brainX/
│
├── BrainX.Api/        # Backend da aplicação
├── BrainX.study/      # Frontend da aplicação
│
├── README.md
└── .gitignore
```

---

## Como Executar o Projeto

### Backend

Acesse a pasta da API:

```bash
cd BrainX.Api
```

Execute o projeto:

```bash
dotnet run
```

---

### Frontend

Acesse a pasta do frontend:

```bash
cd BrainX.study
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
